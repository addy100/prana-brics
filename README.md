## 💡 Executive Summary

**PRANA** (*Predictive Regional Air-quality & Neural Action*) is an India-scale, federated climate defense platform that combines **Einsteinian atmospheric advection-diffusion physics** with **Teslian harmonic sensor resonance** to detect hyper-local pollution spikes and trans-boundary smog corridors. 

Powered by **Google Earth Engine**, **Gemini 1.5 Flash multimodal vision**, and **Vertex AI** with **Bhashini / Google Cloud Speech-to-Text**, PRANA empowers rural farmers, municipal engineers, and state pollution control boards with real-time, multilingual voice alerts and 72-hour predictive vector interception to mitigate regional climate crises across the Indo-Gangetic Plain and BRICS+ corridors.

### 1. Einstein's Continuous Geometric Field
Air is modeled as a continuous geometric manifold where pollutant dispersion obeys the **Advection-Diffusion-Reaction Equation**:

$$\frac{\partial C}{\partial t} + \vec{u} \cdot \nabla C = \nabla \cdot (D \nabla C) + R$$

Where:
- $C$: Pollutant concentration tensor ($\text{PM}_{2.5}, \text{PM}_{10}, \text{NO}_2, \text{SO}_2$)
- $\vec{u}$: Wind velocity vector field ($\text{ERA5}$ Reanalysis / IMD tensors)
- $D$: Turbulent diffusivity tensor
- $R$: Chemical reaction rate & emission source term

PRANA deploys a resonant mesh network of smartphone cameras and low-cost IoT sensors running Fast Fourier Transforms (FFT) on micro-sensor telemetry to catch episodic spikes before macro stations register averages.

## 🧩 Key Product Modules

### 1. 3D Cybernetic Spatio-Temporal Corridor (Three.js)
- **Trajectory Spline**: Catmull-Rom 3D curve with glowing emissive pulses connecting 4 phase milestone beacons.
- **Interactive Beacons**: Icosahedron wireframe geometries with rotating torus rings, raycasting click detection, and smooth camera focus lerping.
- **Aerosol Particle Field**: Particle simulation with Einsteinian wind vector advection ($\text{ERA5}$) and Teslian harmonic wave perturbation.
- **Orbit Controls**: Full drag-to-rotate and scroll-to-zoom interaction.

### 2. Citizen Sky Photo Optical Depth (AOD) Inspector
- Calculates visual range extinction coefficient and Aerosol Optical Depth ($\text{AOD}$) on a 0.0 to 2.5+ hazard scale.
- Features curated sample sky scenarios (Punjab Stubble Smog, Delhi Inversion, Rohtak Haze, Clear Baseline) plus custom image file upload.
- Generates localized vernacular health warnings.

### 3. Einsteinian Advection & Teslian Harmonic Radar
- Solves continuous field advection PDEs for trans-boundary plume migration across inter-state corridors (Punjab $\rightarrow$ Haryana $\rightarrow$ Delhi $\rightarrow$ UP).
- Real-time ground telemetry cards from Central Pollution Control Board (CPCB) stations (Anand Vihar Delhi, Jalandhar, Sector 62 Noida, Rohtak, Durgapur).
- Interactive 72-hour forecast projection output.

### 4. Vernacular Multilingual Voice Action Engine
- Natural voice queries tailored for farmers and municipal dispatchers.
- Vernacular language support in Hindi (*हिंदी*), Punjabi (*ਪੰਜਾਬੀ*), Tamil (*தமிழ்*), and English.
- Native browser Web Speech Synthesis audio playback (`pa-IN`, `hi-IN`, `ta-IN`).

### 5. Interactive 12-Slide Pitch Deck Presenter
- Built-in slide deck presenter featuring all 12 pitch slides from the competition blueprint.
- Category tags, bullet points, LaTeX math equations, slide counter, and keyboard arrow controls (← / → / Escape).

## 🛠️ Local Setup & Installation

### Option A: Direct Web Browser (Zero Setup)
Simply open `index.html` in any browser or launch Python's local HTTP server:
```bash
python3 -m http.server 8085
# Open http://localhost:8085 in your browser
```

### Option B: Full-Stack Node.js Development Mode
```bash
# 1. Clone repository
git clone https://github.com/addy100/prana-brics.git
cd prana-brics

# 2. Install dependencies
npm install

# 3. Create .env file with your Gemini API Key
cp .env.example .env
# Set GEMINI_API_KEY=your_key_here

# 4. Start Node Express Backend API
npm run server  # Runs Express server on http://localhost:8080

# 5. Start Vite Frontend Dev Server
npm run dev     # Runs Vite frontend on http://localhost:3000
```
